Getting back to the camera

Every screen in Tailspot ends by sending you back to the camera, but the button that does it changes shape, size, side and wording from screen to screen. This page lists every exit, draws them to scale, shows how they sit on each iPhone size, and proposes one rule.

"Page go-back icons could be more consistent, perhaps universal bigger back arrow."

"Pages have Done, tap to continue, a small x, a < and all of these take me back the the live capture page."

Gary is right on all three points. The worst cases are the ones people see most often: the Hangar close button and the "tap to continue" line after every catch. The sides also flip. Profile and Leaderboard close from the top left, while the Hangar, Compass and Wikipedia sheets close from the top right.

On each iPhone size

iPhone points are close to the same physical size on every model, about 0.16 mm each. So the 30 pt Hangar X is about 5 mm across on an SE and on a Pro Max alike. Making buttons bigger does not need per-device sizes. What changes between phones is how far the top corners are from your thumb.

Rough one-hand reach, right thumb Exit control

Phones drawn at half a pixel per point, showing the Hangar. The reach area is a fixed 330 pt arc from the lower right corner, so it covers less of the bigger phones. It is an approximation, not a measurement. Gary holds the phone with two hands, which helps with reach but not with seeing a small grey X.

Proposed rule

One question decides the control: does this go back one level, or does it put the screen away?

1Putting a screen away uses an X, top right, 44 pt

  • Hangar, Profile, Leaderboard, Challenges, Compass, Wikipedia, catch detail from the Map, and the full-screen photo.
  • An X, not a down arrow. iOS 26 added a "close" button role for read-only sheets, and the system draws it as an X. A down chevron is Apple's sign for collapsing a media player back into its mini player, which isn't what these screens do.
  • Top right, the outermost slot. It's closer to a right thumb on the bigger phones, and Apple's read-only cards (Maps, Weather) close there too. The Hangar, Compass and Wikipedia exits already sit there. Profile, Leaderboard, Challenges, the photo viewer and the Map's catch detail move over.
  • On the system-toolbar screens it's Button(role: .close), so iOS draws the X and the glass, and VoiceOver reads it as Close.
  • Where an action already sits top right (Share on Profile, the challenges flag on Leaderboard), the X takes the outer slot and the action moves in one place. The Challenges sheet would have three icons up there, so Join and Create should move into the page body.

2Going back one level uses a left arrow, same disc, same place

  • Catch detail and set detail inside the Hangar, and every screen pushed inside Profile.
  • Profile's pushed screens already use the system back button. The Hangar's two custom versions (the bare cyan arrow and the 36 pt blurred disc) change to match it.
  • Back stays top left on every phone. That's where iOS puts it everywhere, and the edge swipe works as the reachable alternative. So there are two places, but each one always means the same thing: left goes back a step, right puts the screen away.

3Every exit is drawn at 44 pt, not only tapped at 44 pt

  • One shared view, something like BackControl(kind: .close | .back), so the size can't drift again.
  • White glyph at 18 pt semibold instead of grey at 13 pt. It grows with the Dynamic Type setting, up to a cap.

4After a catch or a trophy, "Continue" becomes readable and the stronger link

  • Keep the text line, so the card keeps all its height. No full-width button: it would take about 30 pt from the card and compete with the rarity colour.
  • "tap to continue" becomes "Continue" at about 14 pt, semibold, in the main text colour. Today it's 11 pt in the faintest grey on the screen.
  • "View in Hangar ›" steps down to the secondary text colour, so the common action is the one that stands out.
  • The trophy screen's "Tap to continue" gets the same treatment. Tapping anywhere still works on both.
  • New analytics event reveal_dismissed with method (continue, tap_anywhere or view_in_hangar) and dwell_ms. If people turn out to sit on the reveal unsure what to do, that's the case for a bigger control later.

5Forms keep "Cancel"

  • Share, new challenge, join and edit username. Cancel means "throw this away", which is a different promise from closing a screen, and it's what iOS users expect there.

The catch reveal on the smallest and largest phones

A full-width button would take about 30 pt more height than the text line, and the card would shrink to make room on an iPhone SE, where it already shrinks to fit. Keeping the text line and making it readable costs no height on any phone, so the card is the same size before and after.

Decided so far

  1. Glyph: X for putting a screen away, matching the iOS 26 close role. Left arrow for going back a step.
  2. Position: X top right (easier to reach), back arrow top left (iOS convention).
  3. Reveal and trophy exits: a readable "Continue" text link instead of a button, tap-anywhere kept, and a reveal_dismissed event to learn how people leave.
  4. Release: one release, once the change list below is agreed.
