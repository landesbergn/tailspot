# Share formats mockups (2026-10-05)

HTML approximations of the share sheet (`sheet-*.png`) and the PR's three share canvases (Square 1:1, Portrait
4:5, Story 9:16), rendered at 3× in headless Chromium. Not app renders: the
branch was authored without Xcode. Fonts are DejaVu Sans Mono instead of SF
Mono. The Cessna photo is cropped from a real share card; the Boeing hero is
a stand-in for the sky placeholder. For real pixels, run
`ShareCardSnapshotTests` (writes `format_*.png` to `/private/tmp/tailspot_snaps`).
